# Visão geral do WordPress Studio

## O que é o Studio

WordPress Studio é um aplicativo desktop gratuito e de código aberto para criar e desenvolver sites WordPress localmente. Ele prepara WordPress, PHP, banco de dados, HTTPS e um domínio local sem exigir a configuração manual de um servidor.

Está disponível para macOS, Windows e Linux. A base editorial deste projeto é a versão estável 1.17.0.

## Percurso principal do workshop

O workshop usa somente o necessário para a primeira criação:

1. Definir um brief curto e um CTA.
2. Criar um site com o Blueprint **Quick Start**.
3. Planejar e construir com **Studio Code**.
4. Inspecionar e ajustar no **Site Editor**.
5. Registrar comentários com **Annotate**.
6. Compartilhar e atualizar um **Preview Site**.

CLI, Sync, MCP, Liberate, plugins personalizados e publicação em produção ficam fora do exercício principal.

## Limite entre local e remoto

O site local é o espaço de construção e revisão. Um Preview é uma cópia pública e temporária de `wp-content`, não uma hospedagem permanente nem uma sincronização contínua. Sync e publicação permanente são ações remotas separadas.

## Conta WordPress.com

É possível criar sites locais sem conectar uma conta. Login no WordPress.com libera Preview Sites, Studio Code e integrações remotas. Studio Code também exige um método de pagamento cadastrado para prevenção de abuso, embora permaneça gratuito durante o beta e sujeito a limites mensais.

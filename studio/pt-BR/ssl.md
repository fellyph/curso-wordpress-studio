# SSL no WordPress Studio

## HTTPS local

O Studio cria domínios locais com HTTPS para aproximar o ambiente de desenvolvimento do comportamento de um site publicado. Isso ajuda a testar cookies seguros, redirects e recursos que dependem de uma origem confiável.

## Confiar no certificado

O sistema operacional pode pedir autorização para confiar na autoridade certificadora local do Studio. Siga o fluxo exibido pelo aplicativo e confirme apenas certificados gerados pelo Studio instalado na máquina.

## Solução de problemas

Se o navegador mostrar um aviso, verifique se o certificado foi aceito, reinicie o Studio e o navegador e confirme que a data do sistema está correta. Em máquinas administradas, a instalação do certificado pode exigir suporte de TI.

## Uso no workshop

Certificados devem estar resolvidos na verificação prévia. O exercício não reserva tempo para políticas corporativas de dispositivo. A alternativa é demonstrar o site na máquina do instrutor e continuar a edição local sem compartilhar credenciais.

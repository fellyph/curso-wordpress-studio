# Studio Assistant: referência legada

## Status

Studio Assistant foi a experiência anterior de IA no aplicativo. Studio Code tornou-se a experiência padrão e substituiu a aba Assistant. Este arquivo existe apenas para interpretar capturas de tela, gravações e materiais antigos.

## Referência atual

Use [Studio Code](studio-code.md) para requisitos, capacidades, comandos, modelos, sessões e alternativa manual. Materiais novos não devem instruir participantes a abrir a aba Assistant.

## Informações que não devem ser reutilizadas

- limites antigos de prompts ou afirmações de uso ilimitado;
- nomes de modelos desatualizados;
- permissões e fluxos antigos da interface;
- capturas de tela sem versão ou data;
- instruções que tratam Assistant e Studio Code como produtos paralelos.

## Migrar material antigo

Ao revisar um recurso legado, preserve a intenção pedagógica, mas regrave o fluxo em Studio 1.17.x, atualize requisitos e permissões e valide cada ação. Se a imagem for apenas histórica, rotule-a como tal.

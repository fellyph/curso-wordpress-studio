# Perguntas frequentes do workshop

## Preciso instalar PHP, MySQL ou um servidor web?

Não. O Studio fornece o ambiente local. Instale e atualize o aplicativo antes do evento e confirme que você tem permissão para executar aplicações e confiar no certificado local.

## Preciso de uma conta WordPress.com?

Não para criar sites locais. Sim para Studio Code, Preview e integrações remotas. O workshop exige login porque o resultado inclui um Preview.

## Studio Code é ilimitado?

Não. Ele continua gratuito durante o beta, mas exige um método de pagamento cadastrado para prevenção de abuso e tem limites mensais. O instrutor oferece uma alternativa no Site Editor.

## O Preview é privado ou permanente?

Não. Ele é público para quem tem a URL e expira depois de sete dias sem atualização. Não use dados confidenciais e não apresente Preview como hospedagem.

## O workshop publica em produção?

Não. O resultado obrigatório é um site local e um Preview. Sync, exportação e hospedagem são explicados como próximos passos, sem operações em produção.

## Onde ficam meus dados?

O site local fica no diretório escolhido na máquina. Preview envia `wp-content` para um snapshot temporário. Studio Code pode ler e modificar arquivos do site; revise permissões, diffs e comandos.

## Onde buscar ajuda?

Consulte a [FAQ oficial](https://developer.wordpress.com/docs/developer-tools/studio/frequently-asked-questions/), reinicie o aplicativo quando uma sessão ou login não atualizar e use a alternativa preparada em vez de interromper toda a turma.

# WordPress Studio overview

## What Studio is

WordPress Studio is a free, open-source desktop app for creating and developing WordPress sites locally. It provides WordPress, PHP, a database, HTTPS, and a local domain without requiring participants to configure a server manually.

It is available for macOS, Windows, and Linux. This project's editorial baseline is stable version 1.17.0.

## Core workshop path

The workshop uses only what is needed for a first site:

1. Define a short brief and one CTA.
2. Create a site with the **Quick Start** Blueprint.
3. Plan and build with **Studio Code**.
4. Inspect and adjust the result in the **Site Editor**.
5. Capture feedback with **Annotate**.
6. Share and update a **Preview Site**.

CLI, Sync, MCP, Liberate, custom plugins, and production publishing remain outside the core exercise.

## Local and remote boundary

The local site is the space for building and review. A Preview is a public, temporary copy of `wp-content`, not permanent hosting or continuous synchronization. Sync and permanent publishing are separate remote actions.

## WordPress.com account

You can create local sites without connecting an account. Logging in to WordPress.com unlocks Preview Sites, Studio Code, and remote integrations. Studio Code also requires a saved payment method for abuse prevention, although it remains free during beta and is subject to monthly limits.

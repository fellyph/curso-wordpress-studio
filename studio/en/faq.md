# Workshop frequently asked questions

## Do I need to install PHP, MySQL, or a web server?

No. Studio provides the local environment. Install and update the app before the event, and confirm that you are allowed to run applications and trust the local certificate.

## Do I need a WordPress.com account?

Not for local sites. Yes for Studio Code, Preview, and remote integrations. The workshop requires login because the expected result includes a Preview.

## Is Studio Code unlimited?

No. It remains free during beta, but requires a saved payment method for abuse prevention and has monthly limits. The facilitator provides a Site Editor fallback.

## Is Preview private or permanent?

No. It is public to anyone with the URL and expires after seven days without an update. Do not use confidential data or present Preview as hosting.

## Does the workshop publish to production?

No. The required outcome is a local site and a Preview. Sync, export, and hosting are explained as next steps without production operations.

## Where is my data?

The local site lives in the chosen directory on the machine. Preview sends `wp-content` to a temporary snapshot. Studio Code can read and change site files; review permissions, diffs, and commands.

## Where can I get help?

Consult the [official FAQ](https://developer.wordpress.com/docs/developer-tools/studio/frequently-asked-questions/), restart the app when a session or login does not refresh, and use the prepared fallback rather than blocking the whole group.

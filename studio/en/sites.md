# Local sites in WordPress Studio

## Create a site

For the workshop, use **Add site**, choose **Build a new site**, select the **Quick Start** Blueprint, name the site, and confirm. Everyone starts from the same foundation while applying their own brief.

Studio 1.17 can also start site creation from imports. That path is reserved for facilitator setup and fallback materials.

## Site settings

Site settings can change the local domain, WordPress and PHP versions, runtime, administrator credentials, and debugging options. Do not change the runtime or versions during the exercise without guidance: doing so makes results harder to compare and support.

## Available actions

For each site, you can start, stop, duplicate, open the local site, enter WP Admin, open the Site Editor, access files and database tools, and use Studio Code, Preview, and Sync tabs when available.

## Credentials and Preview

Local-site credentials are separate from the WordPress.com account. Preview requires a WordPress.com login and creates a temporary copy; it does not turn the local site into permanent hosting.

## Delete a site

Deleting a site removes its local environment and can delete associated files and sessions. Export anything that must be retained first. Never use the facilitator's finished site as the target of a deletion test.

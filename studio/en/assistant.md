# Studio Assistant: legacy reference

## Status

Studio Assistant was the app's earlier AI experience. Studio Code became the default experience and replaced the Assistant tab. This file exists only to interpret old screenshots, recordings, and materials.

## Current reference

Use [Studio Code](studio-code.md) for requirements, capabilities, commands, models, sessions, and fallback. New materials must not instruct participants to open an Assistant tab.

## Information that must not be reused

- old prompt limits or unlimited-use claims;
- outdated model names;
- old interface permissions and flows;
- screenshots without a version or date;
- instructions that treat Assistant and Studio Code as parallel products.

## Migrate old material

When revising a legacy resource, preserve its teaching intent but record the flow again on Studio 1.17.x, update requirements and permissions, and validate every action. If an image is only historical, label it clearly.

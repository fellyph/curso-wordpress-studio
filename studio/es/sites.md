# Sitios locales en WordPress Studio

## Crear un sitio

Para el workshop, selecciona **Add site**, elige **Build a new site**, selecciona el Blueprint **Quick Start**, asigna un nombre al sitio y confirma. Todo el grupo comienza con la misma base mientras aplica su propio brief.

Studio 1.17 también puede iniciar la creación de un sitio a partir de importaciones. Ese recorrido se reserva para la preparación del facilitador y los materiales de fallback.

## Ajustes del sitio

Los ajustes del sitio permiten cambiar el dominio local, las versiones de WordPress y PHP, el runtime, las credenciales de administración y las opciones de depuración. No cambies el runtime ni las versiones durante el ejercicio sin orientación: hacerlo dificulta comparar resultados y prestar soporte.

## Acciones disponibles

En cada sitio puedes iniciar, detener, duplicar, abrir el sitio local, entrar en WP Admin, abrir el Site Editor, acceder a los archivos y a las herramientas de base de datos, y usar las pestañas Studio Code, Preview y Sync cuando estén disponibles.

## Credenciales y Preview

Las credenciales del sitio local son independientes de la cuenta de WordPress.com. Preview requiere iniciar sesión en WordPress.com y crea una copia temporal; no convierte el sitio local en alojamiento permanente.

## Eliminar un sitio

Eliminar un sitio borra su entorno local y puede eliminar archivos y sesiones asociados. Exporta primero todo lo que deba conservarse. Nunca utilices el sitio terminado del facilitador como objetivo de una prueba de eliminación.

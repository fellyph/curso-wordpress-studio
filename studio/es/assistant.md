# Studio Assistant: referencia heredada

## Estado

Studio Assistant fue la experiencia de IA anterior de la aplicación. Studio Code se convirtió en la experiencia predeterminada y reemplazó la pestaña Assistant. Este archivo existe solamente para interpretar screenshots, grabaciones y materiales antiguos.

## Referencia actual

Utiliza [Studio Code](studio-code.md) para requisitos, capacidades, comandos, modelos, sesiones y fallback. Los materiales nuevos no deben indicar a los participantes que abran una pestaña Assistant.

## Información que no debe reutilizarse

- límites de prompts antiguos o afirmaciones de uso ilimitado;
- nombres de modelos desactualizados;
- permisos y flujos de interfaz antiguos;
- screenshots sin versión ni fecha;
- instrucciones que tratan Assistant y Studio Code como productos paralelos.

## Migrar material antiguo

Al revisar un recurso heredado, conserva su intención educativa, pero vuelve a grabar el flujo en Studio 1.17.x, actualiza requisitos y permisos, y valida cada acción. Si una imagen es solamente histórica, identifícala claramente.

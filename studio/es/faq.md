# Preguntas frecuentes del workshop

## ¿Necesito instalar PHP, MySQL o un servidor web?

No. Studio proporciona el entorno local. Instala y actualiza la aplicación antes del evento y confirma que tienes permiso para ejecutar aplicaciones y confiar en el certificado local.

## ¿Necesito una cuenta de WordPress.com?

No para los sitios locales. Sí para Studio Code, Preview y las integraciones remotas. El workshop requiere login porque el resultado esperado incluye un Preview.

## ¿Studio Code es ilimitado?

No. Continúa siendo gratuito durante la beta, pero requiere un método de pago guardado para prevenir abusos y tiene límites mensuales. El facilitador proporciona un fallback en el Site Editor.

## ¿Preview es privado o permanente?

No. Es público para cualquier persona que tenga la URL y caduca después de siete días sin una actualización. No utilices datos confidenciales ni presentes Preview como alojamiento.

## ¿El workshop publica en producción?

No. El resultado obligatorio es un sitio local y un Preview. Sync, exportación y alojamiento se explican como próximos pasos sin realizar operaciones en producción.

## ¿Dónde están mis datos?

El sitio local se encuentra en el directorio elegido en el equipo. Preview envía `wp-content` a una captura temporal. Studio Code puede leer y modificar los archivos del sitio; revisa permisos, diffs y comandos.

## ¿Dónde puedo obtener ayuda?

Consulta la [FAQ oficial](https://developer.wordpress.com/docs/developer-tools/studio/frequently-asked-questions/), reinicia la aplicación cuando una sesión o el login no se actualicen y utiliza el fallback preparado en lugar de bloquear a todo el grupo.
